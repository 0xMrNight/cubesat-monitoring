# Machine Learning Notebooks

The notebooks folder contains the Jupyter notebooks used to prepare the telemetry data and develop the anomaly-detection model.

- **01_data_creation_and_fault_injection.ipynb** – Creates telemetry data and introduces simulated faults.
- **02_model_training.ipynb** – Trains the Isolation Forest anomaly-detection model.
- **requirements.txt** – Contains the notebook dependencies.
